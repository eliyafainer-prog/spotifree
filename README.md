# 🎵 SpotiFree — Ad-Free Music Streaming PWA

> נגן מוזיקה עצמאי, ללא פרסומות, בעיצוב מדויק של Spotify. תמיכה מלאה במחשב ובטלפון (PWA), שליטה מהאוזניות וממסך הנעילה, ייבוא פלייליסטים מספוטיפיי/יוטיוב ומילים מסונכרנות בזמן אמת.

---

## ✨ תכונות עיקריות (Features)

- 🚫 **100% ללא פרסומות (Ad-Free):** הזרמת שמע רציפה ללא פרסומות, ללא הגבלת דילוגים ובחינם לחלוטין.
- 🎧 **תמיכה מתקדמת באוזניות ובמסך נעילה (MediaSession API):**
  - תמיכה מלאה בכפתורי אוזניות בלוטות' / חוטיות (Play/Pause, שיר הבא/קודם, הרצה).
  - הצגת שם השיר, האמן ועטיפת האלבום ברזולוציה גבוהה במסך הנעילה ובווילון ההתראות.
  - סרגל התקדמות חי (Scrub Bar) שניתן לגרור ישירות ממסך הנעילה.
  - **עצירה אוטומטית בניתוק אוזניות:** בעת כיבוי או ניתוק האוזניות, הנגן עוצר אוטומטית כדי לא להשמיע סאונד ברמקול הפומבי.
- 📱 **רספונסיבי וניתן להתקנה (PWA):**
  - **במחשב (Windows):** ניתן להתקנה כתוכנה עצמאית ללא מסגרת דפדפן.
  - **בסמארטפון (Android / iOS):** לחיצה על "הוסף למסך הבית" מתקינה את האפליקציה במסך מלא עם ניגון חלק ברקע כשהמסך כבוי.
- 🔗 **ייבוא פלייליסטים חיצוניים (Spotify & YouTube Importer):**
  - הדבקת קישור פלייליסט או אלבום מספוטיפיי / יוטיוב מייבאת אותו מיידית לספרייה האישית שלך.
- 🎤 **מילים מסונכרנות בזמן אמת (Synced Lyrics):**
  - מילים קריוקי מבוססות חותמות זמן (LRCLIB).
  - השורה הנוכחית מודגשת ונגללת אוטומטית למרכז.
  - לחיצה על כל שורה בשיר מקפיצה את הנגן מיידית לאותה שנייה.
- 🎨 **ממשק Spotify Dark Theme אותנטי:**
  - סיידבר, סרגל נגן תחתון מלא, נגן מסך מלא למובייל (Swipe Up), גריד אלבומים ושירים שאהבתי.
- 💾 **שמירה מקומית (Offline Storage):**
  - כל הפלייליסטים, השירים שאהבת (Liked Songs) וההיסטוריה נשמרים ישירות במכשיר שלך.

## 🛠️ טכנולוגיות (Tech Stack)

- **Frontend:** React 18, Vite, Tailwind CSS, Lucide Icons, HTML5 Web Audio API, MediaSession API.
- **Backend:** Node.js, Express, Axios, `yt-search`, `yt-dlp` audio resolver.
- **Lyrics:** LRCLIB API.

## 🚀 התקנה והרצה (Quick Start)

### 1. דרישות מוקדמות
- **Node.js** (גרסה 18 ומעלה)
- **Python** (עם חבילת `yt-dlp`: `pip install yt-dlp`)
- **Git**

### 2. התקנת תלויות
פתח את הטרמינל בתיקיית הפרויקט והרץ:
```bash
# התקנת תלויות השרת והקליינט בפקודה אחת
npm run install:all
```

### 3. הרצה במצב פיתוח
```bash
npm run dev
```
- הממשק ייפתח בדפדפן בכתובת: `http://localhost:3000`
- שרת ה-Backend ירוץ בכתובת: `http://localhost:5050`

## 📱 כיצד לפתוח מהטלפון הנייד (Mobile Access)
1. ודא שהטלפון והמחשב מחוברים לאותה רשת Wi-Fi ביתית.
2. פתח טרמינל במחשב ובדוק את כתובת ה-IP המקומית שלך (למשל `ipconfig` ב-Windows, בדוק את כתובת ה-IPv4, לדוגמה `192.168.1.15`).
3. בדפדפן בטלפון (Chrome / Safari), היכנס לכתובת:
   ```
   http://<YOUR-IP>:3000
   ```
4. לחץ בתפריט הדפדפן על **"הוסף למסך הבית" (Add to Home Screen)**.
5. תהנה מספוטיפיי ללא פרסומות, עם תמיכה מלאה באוזניות ובמסך הנעילה!

הפרויקט כבר מאותחל כמאגר Git מקומי עם קובץ `.gitignore` מסודר.

כדי להעלות אותו לחשבון ה-GitHub שלך:
1. פתח מאגר חדש (New Repository) ב-GitHub (למשל בשם `spotifree`).
2. הרץ בטרמינל בתיקיית הפרויקט:
```bash
git add .
git commit -m "Initial commit: SpotiFree ad-free music streaming PWA"
git branch -M main
git remote add origin https://github.com/<YOUR-USERNAME>/spotifree.git
git push -u origin main
```
